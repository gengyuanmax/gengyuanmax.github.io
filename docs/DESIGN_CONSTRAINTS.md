# 全局设计约束

更新：2026-10-14。适用：这个个人主页的主版本、设计台、独立预览及构建产物。

本文是后续调整的设计基线。用户最新明确反馈优先于本文；本文优先于旧实验、历史交接片段与通用风格示例。修改设计规则时同时更新本文和对应实现，避免只改某个页面。用户于 2026-10-14 授权先发布当前快照作为首个在线版本；这不代表每条文案永久定稿。

## 1. 一个主版本

- **1440 CSS px 是唯一主设计画幅**（页面内容上限仍为 1280px）。先在此画幅判断构图、层级和节奏，其他宽度仅从它派生适配，不作为平行设计方案。
- 只维护当前主版本，不恢复 A/B/C 切换，不从旧 mockup 重新开始。旧方案位于 `design-lab/archive/`，只作历史参考。
- 首页阅读顺序已确认：**姓名 → 个人介绍与联系方式 → 研究品牌与三个关注方向 → News**。DOM、视觉排列和键盘阅读应表达同一顺序。
- Profile/contact 是独立个人信息区；研究品牌不能和个人信息混排。三个方向是 slogan 的具体展开，默认通过三色叠印圆表达交叉关系。
- 1440 主版沿用已选 B：左侧品牌、右侧三色叠印圆；小于 1024px 时圆移到标题下方，小于 640px 时为 160px 图例加三个方向入口。
- 每屏主视觉集中在姓名与人像。其余文字、线条仍服从油墨规则，但不逐块增加粗网、圆圈和大幅错版。
- **Artifacts 保持自己的风格**：各作品原预览与独立编排可以不同，不统一套 Print Labs 卡片，不给所有缩略图再染色。

实现入口：`src/config/main-version.ts`、`src/components/areas/Home.astro`、`src/styles/home-main.css`、`src/client/home-branches.ts`。

## 2. 两墨与纸

主页主体的视觉用墨只来自**蓝墨、朱红墨、两墨叠印、纸**；研究圆允许第三块黄色版（第 14 节），Print Labs 插页胶带的局部黄色例外见第 13 节。不要新增独立黑墨/灰墨来表示正文、日期或分隔线。抗锯齿、纹理和屏幕混合会产生中间像素值，这不是要求把最终截图量化为四个 RGB 值。

| 角色 | 规则 |
| --- | --- |
| 正文、日期、mono 标签 | 蓝墨实色；用字号、字重、行距和位置表达层级，不靠灰色或降 opacity |
| 品牌、区块标题 | 蓝墨主体，可用共享朱红底版叠印；保持完整可读 |
| 当前导航与强调点 | 朱红状态墨；可与蓝墨叠印，不增加新强调色 |
| 正文强调 | 沿用当前正文与蓝墨，以字重强调；不恢复旧网点强调带，不伪装成链接 |
| 链接 | 有明确可点击提示与焦点样式；下划线留给实际链接 |
| 浅色块、次要底形 | 用共享网点覆盖率表达浅墨，不能独立手调一种灰色或透明墨色 |
| 线条与连接关系 | 使用这两种墨；连接必须有实际语义，交叉可出现叠印色 |
| 纸张与颗粒 | 克制，不能妨碍正文；新纸纹不得引入一套额外墨色 |

原始作品图、科研图和素材源文件不受“重染成两墨”的要求；保留其信息和色彩含义。分版/网点诊断视图可以使用专用标记色，但仅在本地开发检查层出现。

## 3. 全页共享的物理参数

“固定”指**同一页每种墨使用同一个值**，不等于这些数值永远不能调整。需要改时改全局来源，不给单个元素另开一台印刷机。

| 参数 | 当前基线 | 调整规则 |
| --- | --- | --- |
| 纸色 | `#f0ebdf` | 共享纸色来源 |
| 蓝墨 / 主墨 / b | `#283eb5` | 全页同一色值 |
| 朱红 / 第二墨 / a | `#cf5037` | 全页同一色值 |
| 蓝网角 | 75° | 全局同步 |
| 朱红网角 | 15° | 全局同步；不照抄历史示例中的反向命名 |
| 点形 | 两墨当前都是圆点 | 每墨只用一种形状；圆/方只能在全局改 |
| 套版偏移 | 蓝版相对朱红参考版 X +2px / Y +1px | 所有双墨对象共用；禁止元素独立偏移 |

当前渲染约定是 **a=朱红参考版，b=蓝偏移版**。不要把用户讨论中的示例代码当成反向更换墨层的指令。

`resolve()` 中的 `pageLocked` 统一解析墨色、网角、点形和套准；旧局部配方可被读取，但不得覆盖这些全局参数。叠印使用共享 multiply 逻辑；这是一种屏幕模拟，不是印厂分色文件。

## 4. 只有三档网点

| 档位 | 当前频率 | 用途 |
| --- | --- | --- |
| coarse · 字级 | `1/16em`，按实际字号取整到 CSS px | 大字姓名的表现性蓝网层；当前桌面约 8px |
| medium · 图像 | 4 CSS px | 人像、相邻圆形底版和其他几何 |
| fine · 细网 | 2 CSS px | 浅墨底形、背景、分隔区域，以及窄屏显示级姓名 |

- 唯一频率来源是 `src/design/screen.ts` 的 `screen(level, ink)` 与 `--screen-*` tokens。不要在组件里新增 3px、5px、6px 等自由网距。
- 字级随字号变化；平网/图像用固定 CSS px。实际渲染的网距取整；当前字级与图像档相差不足 1.5 倍时复用 fine 细网，避免看似误差的第四档；由共享 `typeScreenLevel()` 按实际字号选择，不按画幅切换成实色。
- 同色、相邻或重叠的对象使用同一档。人像与背后的圆一起用 medium。
- 可以按对象调整浓度、影调和覆盖率；不能同时改变同种墨的全局角度、形状或套准。
- 当前主版本采用 AM。未来若引入 FM，须作为明确的元素类型规则并更新本文，不开启逐元素自由算法切换。
- 不要求每屏凑齐三档。网点检查视图报告实际显示的档位，实色不计入。
- 整数 CSS px 不能保证在所有设备像素比或浏览器缩放下完全无摩尔纹。缩略预览会重采样网点；检查纹理用原尺寸。

## 5. 可读性与语义底线

- 姓名必须一眼可读。按最新字号分级：≥72px 保留朱红实色底与蓝网层；窄屏姓名小于72px时采用清晰的双墨实色。1440 当前 8px 网距保持；约 16px 及以下的小字规则仍适用。不恢复旧粗网和大错位。
- 24px 以下阅读字保持单墨实色，不挂网、不加噪声或可见错版（最新修订见第 16 节）。全页模拟双墨印刷，不要求每一个字都同时上两墨。
- 装饰副本对辅助技术隐藏；真实文字只出现一次。新双墨标题沿用 `InkText` / `PrintTitle` / `PrintWord`，不复制两份可朗读的 DOM。
- 装饰不能截获点击、遮挡文字或焦点。连接 SVG 为装饰，标题、列表和真实项目链接在无 JS 的 HTML 中仍成立。
- 保留键盘操作、可见焦点、减少动态效果支持；不要用横向裁切隐藏布局溢出。
- 普通文字对比度目标至少 4.5:1，大字至少 3:1；实际纸色、网点背景和叠印处都要检查。

## 6. 共享网格与响应式

- 桌面共用 12 列，小容器共用 4 列。导航、姓名/介绍、品牌分支与 News 落在同一套列线上，不各自另开坐标系统。
- 内容层完整且有序，表现层才可以有限错位。结构错位不能代替全局油墨套准。
- 当前 Home 的间距参数为 56px，品牌字号参数为 56px；这是可调基线，实际显示字号遵循响应式规则。
- News 在所有宽度使用单栏时间流，日期与正文分列；没有装饰圆圈和重复日期短条。已知日期按月/年展示；只有年份的记录保留年份，不编造月份。
- 断点取决于页面容器，不要把浏览器宽度与内容宽度混为一谈。测试至少覆盖 1440、768、375、320px，并在涉及断点变化时查看中间尺寸。

## 7. 设计台、独立预览与发布必须同源

- 首页和设计台共用组件、CSS、参数解析与素材管线。不能用设计台专属 DOM 改写来做一套正式页面没有的构图。
- **设计台和独立预览默认都用同一张 1440px 主版画布**，窗口变窄时只缩小展示，不偷偷切换断点。整幅 / 原尺寸切换只改变查看方式；1440 原尺寸用于网点检查。
- 其他尺寸明确归为「适配检查」，不能覆盖主版默认画幅。真实网站仍按浏览器宽度响应式排版，不给手机访客强制缩小一整张桌面页。
- 「独立预览 1440 主版」必须带入当前会话草稿，不能悄悄改用已保存配置。未保存的预览要标明状态；保存才更新 `src/config/design.json`。
- `/design/?view=preview` 是同一设计台隐藏控制面板后的独立画布，仍使用当前会话草稿和 1440 主版；不要另建一套预览组件。直接访问 `/` 使用已保存的响应式网站。旧的 `/?design-preview=current` 仍可作为响应式草稿检查入口，不是主版独立预览。
- 比较效果时先对齐配置、实际排版宽度、缩放与设备像素比，并关闭网格/网点诊断/单墨分版。缩小后的网点观感不能用来判断素材管线是否不同。
- 检查视图、编辑面板、保存接口和草稿逻辑不得进入发布产物。

相关实现：`src/design/preview-state.ts`、`src/client/studio.ts`、`src/client/preview.ts`、`scripts/design-server.ts`。

## 9. 每次调整的落地方式

1. 先读本文，确认改动属于全局规则、可调基线、单个元素还是公开内容。
2. 改共享来源；不要新建另一套实验首页来绕过主版本。
3. 用同一配置、同一宽度核对设计台与独立预览。涉及网点时检查单墨与档位视图，涉及文字时检查窄屏与重复朗读。
4. 运行与改动有关的检查。代码改动使用现有测试、`npm run check` 和构建验证；保存接口改变时运行 `npm run test:server`。仅文档修改不需要重跑整站。
5. 用户改变全局规则时，同步本文、对应 token/实现和必要测试；交接文档只记录过程，不取代本约束文档。

代码已强制的部分包括参数范围/作用域、全局物理参数、三档频率、已选方案收敛和发布隔离。视觉焦点、文案确认、对比度与响应式观感仍需人工审阅；测试通过不代表所有设计约束自动验收。

## 10. 首页分隔与动态（2026-10-14）

- 当前分隔处理为个人介绍 → 研究的双墨章节线，以及研究 → News 的 28px fine 细网过渡带。News 标题以纸色留白压住色带，条目正文保持干净纸面与单墨细线。
- 章节线共用全页墨色与套准；News 网带共用 fine 频率、蓝版网角、点形和材质管线。过渡带默认墨量 .18，可调 .08–.30，不以透明度替代网点。
- 两版首次进入视口时用遮罩印出，持续 700ms，蓝版延迟 110ms。动画不拉伸网点、不改变套准；减少动态效果、无 JS、打印与高对比度环境均保留完整内容。印出动态是共享分隔规则，不应用于正文。
- 设计台在现有主版本内提供「双墨章节线 + News 细网过渡 / 原细线对照」及全局静态/首次印出控制；不新建平行首页。正式页面、设计台与独立预览读取相同配置。
- 全局约束允许调整；调整必须同步共享来源和所有受影响对象，不能为单个分隔私设墨色、网角或套准。本轮不引入日期随机变化。

## 13. Print Labs 作为独立印刷品（2026-10-14 修订）

- 原图与原色保留，只加 6px 纸边。无描边、相框、错层阴影或投影。
- 胶带沿用 Layout Lab tapeClip 的结构：两条长边直、两个短边有 seeded 撕口；作为独立覆盖层，跨过页面、纸边与图像，不是边框上的标签。
- 仅插页附件允许黄色专色 #f2df8a；multiply 与 .85 屏幕透明度模拟透底，细颗粒复用 fine 2px 尺度，无黑色颗粒。此例外不推广到主页正文、导航或其他作品。
- 全局 seed 与插页序号共同决定顶部中央、双端或单端贴法、位置、长度和 ±8° 角度；相同 seed 重现相同贴法。设计台与正式页面共用 insertTapes，胶带不截获点击。
- Layout Lab 源码的胶带还带渐变与投影；本实现按用户要求省略这两者，保留平面叠印。胶带可覆盖少量图像上缘但不改变源图文件。

- Print Labs 现在以一张 2×2 总览 SVG 封面呈现，四张原图内嵌保留原色；整个封面是一张插页、一个项目入口、一组胶带。桌面最大 280px、窄屏最大 300px，不再把四个 Lab 展开成四张独立纸片。

## 14. 首页研究方向的 Canvas 印刷配方（2026-10-14）

- 用户最终要求继续横排，忽略三角形建议；三个等大圆不是包含关系，首页没有项目标签。现有方向链接、数据与触屏点选/键盘交互不变。
- 圆组在右侧第 6–12 列，画框 800×500，主版最大 640×400 CSS px。间距/半径默认为 1.33（约 4/3），相邻圆沿水平方向重合约直径的 1/3，可调 .55–1.4；中圆下移 18 个设计单位。向外拉开时半径自动适配画框留白。小于 640px 时为 160×100 图例和方向列表。不能声称横排具备全部七个可读分区。
- 真实显示使用 Canvas，像素大小为 CSS 尺寸 × DPR。每版正常/强调/退后三张离屏画布预生成，悬停只合成；resize 防抖 200ms。无 JS 的 PNG 后备使用同一组多边形与参数生成，不在页面使用 SVG pattern。没有描边、纸色弧线、蒙版切口或阴影。
- 研究圆采用独立、共享于本模块和设计台的印版配方。用户指定蓝 15°、橙 75°、黄 0°；这些是 researchBlueAngle/researchOrangeAngle/yellowAngle，不改变人像和其他组件的蓝 75°/朱红 15°。
- 默认 7 CSS px 整数网距，中心抖动 ±10%；点面积由目标墨量决定，半径再浮动 ±10%。网点为 12 顶点不规则多边形，顶点半径 ±8%；掉点阈值 .06，扩大系数 1.12，墨量大于 .88 使用连点半径。此阈值分支可测试，默认密度不保证每版都有糊版。
- 色调场 = 0.85r 到 r 的 smoothstep 边缘衰减 × 向全图中心汇聚的 .15–.65 墨量 × 每版独立四层 fBm（250px，±15%）× 独立走纸一维浅带（最多 20%）× 全版共享高频纸纤维（6.5%）。噪声仅调墨点，不通过整块透明度变浅。
- 随机数沿用 Print Lab 的 seeded mulberry32；researchSeed=0 表示 Europe/Brussels 当天 YYYYMMDD，同一天重载一致；明确 seed 固定全部细节。纸张 ±2% 明度噪声也由同一 seed 派生。
- 蓝版为 (0,0)/0°/1 的参考版；橙版约 (+1.5,-1)/+0.15°/1.002，黄版约 (-1,+1.5)/-0.2°/.998，seed 增加极小扰动。变换以画布中心为原点，偏移随位置变化。强调归零；reduced motion 时只改变网点状态，不移动版。
- 按黄→橙→蓝 multiply 合成，globalAlpha=.9 作为用户明确允许的墨层物理透明度例外。页面其他组件的双墨与透明度规则不变。
- 标签为 18px 展示字体粗体蓝墨，沿各自圆外的同心弧排布：蓝/黄上弧、橙下弧，字形距圆边约 14px。文字路径随圆心、半径和画幅更新，不缩小字号；弧形命中带至少 28px，保留真实链接、键盘焦点下划线与触屏操作。手机保留正常方向列表。进入动画仍为蓝→橙→黄，间隔 250ms，每版 220ms，只播放一次；reduced motion 跳过。状态变换 220ms，重播仅设计台可用。
- 设计台可调间距、上下偏移、网格、掉点、网点扩大、三类噪声、seed、网角和套准；分版通过合成时只选择对应离屏版实现。

## 16. 清晰文字配方（用户最新修订，取代上一轮侵蚀配方）

- `sharp-type-v3`：任何文字不使用 SVG 滤镜、颗粒、孔洞或字缘侵蚀；真实 DOM 保持锐利轮廓。
- ≥72px 展示字：实色底可有最多5%的32 CSS px低频减墨；需要网点的姓名仅有一层均匀蓝点，默认半径为网距 .37，可调范围 .25–.38，不做扩大、挖洞或网点噪声。
- 24–72px 标题：双墨实色，低频墨量变化最多4%，不挂网。16–24px 未列出的区间按正文保护；24px以下单墨实色，无效果。
- 文字单独将全局套准封顶为 X .75px / Y .5px（负值同样限幅），图像/色带保持全局参数。小字无错版。
- 网点按完整均匀网格生成，再由字形裁切；保留边缘半点，不随机删点，不柔化。网点字仅在CSS中套准一次，X/Y各限幅0.5px，其他标题保留受限套准。固体文字仅使用低频材质场，不重新栅格化字形轮廓；点阵使用真实字形覆盖率确定容纳区域。
- 文字不再叠加 `paintMaterial` 的图像颗粒。原 grain/starvation 等全局值仍服务图像和色带，不能据此推算文字墨量；旧迁移基准仍保留。

## 17. 页面噪声坐标与原版对照（2026-10-14）
