## 共享修复及回归保护

- `ink-group.ts`：已转印覆盖率按墨色取 max，再异墨合成；不靠 RGB multiply 冒充同墨合版。
- `ink-rects.ts` / `print-guides.ts`：相接同色规则线分组，包含时间轴和边框转角，避免逐处修补。
- `raster-composite.ts`：同一调用内重复 ink ID、相同 opaque 语义先合并；明确 opaque 操作保持独立。
- `route.ts` / `print-routes.ts`：共享路径并集、分带余量裁切、屏幕像素对齐。
- `print-rules.ts`：已印刷色标、图标及合版输出不再重复加工。
- 回归测试覆盖同墨合成、异墨叠印、规则线连接与桥接、路线交点、分带重建，以及静态元素排除。

验证：158 项测试通过；Astro 检查 0 errors / 0 warnings（12 hints）；生产构建通过。浏览器所检宽窄布局未发现水平溢出。

## 边界

这不是对任意 DOM 元素自动全页分色。跨 DOM 相交仍需显式加入共享合版组。无 JS、合版尚未完成或失败时，原 DOM / 静态后备仍不保证跨元素同墨并集。此次没有遍历设计台全部历史方案、主题、任意屏幕尺寸或未启用的 portrait-flow / 树状首页方案；也未将本地修改发布到线上。
