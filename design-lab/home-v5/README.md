# Layout review 06

An isolated design prototype, outside Astro's source and public directories. It does not replace the homepage or enter the current deployment build.

The directory name is retained so the existing preview URL continues to work. The preceding source snapshot is at `homepage-planning/revisions/v5/` in the workspace.

`foundation.css` owns the type roles, candidate palette and spacing. `home.css` owns the Home composition and portrait-to-News geometric cue. `sections.css` adds the geometric navigation marks, Research chapter shortcuts, staggered Research composition and mixed Artifacts spread. `interaction.js` provides the four-area preview, fragment navigation and optional review controls.

Research has three directly linked subsections, also reachable from the Home pillars. Artifacts are interleaved by editorial prominence and content length. Form labels such as article or demo do not define separate sections or a fixed placement rule.

Screening, ink combinations and print defects remain unconfirmed. The current colors and portrait are temporary review treatments. Missing Research and Artifacts imagery is explicitly marked as a placeholder.

The large name is copied from the existing site configuration. The research theme and pillar concepts come from the user; `[Machines]` remains a provisional label. Biography and News remain explicit placeholders. All final wording, image treatment and layout await user review.

The image is a built-in imagegen treatment of `assets/img/portrait3.jpeg`. Source pixels are not guaranteed unchanged. The original source and full PNG output are preserved separately; this directory contains a compressed WebP for review. The exact prompt and provenance are in `homepage-planning/assets/portrait3-riso-review.json` at the workspace root.

The same source is embedded in the conversation preview. Browser rendering, responsive behavior, font appearance and image edges still require visual verification; static validation alone does not establish those outcomes.
